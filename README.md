# 🎵 Archivarius: Music Station

**Music Station** — это мощное десктопное приложение на Python (PySide6) для глубокой очистки, умной дедупликации, редактирования тегов и структурирования музыкальных библиотек.

## ✨ Ключевые возможности
- **Интеллектуальная дедупликация:** Автоматический поиск мастер-релизов, слияние синглов и EP, распознавание ремиксов (Remix), караоке (Karaoke) и гостевых участий (Feat).
- **Массовый редактор тегов:** Вшивание обложек, текстов песен, каскадные фоллбэки для пустых тегов и автовосстановление битых кодировок (CP1251 -> UTF-8).
- **Очистка от мусора:** Умный алгоритм, удаляющий из названий ссылки на сайты (vk.com, t.me), рекламу, битрейт (`[320 kbps]`) и технические приписки (`Official Video`).
- **Мощный экспорт и транскодинг:** Перекодирование на лету с помощью FFmpeg (CBR/VBR), нормализация громкости (EBU R128), конвертация WebP-обложек в JPEG/PNG.
- **Инструменты AI:** Генерация структурированных промптов для аудита фонотеки через ChatGPT / Claude.

## 🛠 Требования к системе
* **Python** 3.9 или выше.
* **FFmpeg**: должен быть установлен в системе и добавлен в переменную `PATH` (для транскодирования аудио).

## 🚀 Установка и запуск
```bash
1. Клонируйте репозиторий:
   git clone https://github.com/Gorge228/Music-Station.git
   cd MusicStation

2. Создайте и активируйте виртуальное окружение:
   
    Для Windows:
    python -m venv venv
    venv\Scripts\activate

    Для Linux / macOS:
    python3 -m venv venv
    source venv/bin/activate

3. Установите зависимости:
    pip install -r requirements.txt

4. Запустите приложение:
   python src/ui/main_window.py
